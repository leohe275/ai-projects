# 飞书应用手动发布指引

## 问题说明
当前应用的 im:chat:readonly 权限尚未开通，无法通过 API 获取群聊列表和发送消息。

## 解决步骤

### 步骤1：开通权限
1. 打开 https://open.feishu.cn/app/cli_aa8ec1c206f89cc7/auth
2. 搜索：im:chat:readonly
3. 勾选并申请开通

### 步骤2：创建并发布版本
1. 应用详情页 → 版本管理与发布
2. 创建新版本：1.0.1
3. 描述：开通im:chat:readonly权限并自动发布
4. 保存并发布

### 步骤3：添加机器人到群聊
1. 打开飞书群 → 群设置 → 群机器人
2. 添加机器人 → 搜索你的应用
3. 添加完成
